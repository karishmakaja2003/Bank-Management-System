# Bank Management System

This is a console-based Java application that simulates basic banking operations. It allows users to register customers, create accounts, deposit and withdraw funds, and check balances.

## Features
- Customer registration
- Account creation
- Deposit & withdrawal
- Balance inquiry
- CLI-based interaction

## Technologies Used
- Core Java
- Object-Oriented Programming
- IntelliJ IDEA

## How to Run
1. Open the project in IntelliJ or any Java IDE.
2. Run the main Java file (e.g., `Main.java`).
3. Follow the menu to perform banking operations.
